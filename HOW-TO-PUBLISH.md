# Forged in Exile on GitHub Pages

The game is hosted free on GitHub Pages from this repository. Any change pushed to the main branch goes live within a minute or two at:

https://rdtradez.github.io/forged-in-exile/

## Moving saves from the old Netlify site

Saves are stored in the browser and tied to the website address. Open `transfer.html` on the old site, make a transfer code and copy it. Then open `transfer.html` on the new site and paste it in. Every book's saves come across.

## Installing on a phone

Open the site in Chrome on Android, then use the menu and choose "Install app" or "Add to Home screen".
